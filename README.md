# Sarvatra App – Android On-Demand Services

Sarvatra is a service-based Android application that offers a seamless platform for booking essential on-demand services such as beauty care, home repairs, cleaning, and delivery — all from your smartphone.

## 🔧 Built With

- Java & Android SDK
- Figma (for UI/UX design)
- XML layouts

## ✨ Features

- 🧖 Beauty Services at your doorstep
- 🛠 Home Repairs by trusted professionals
- 🧹 Easy Cleaning Service Booking
- 📦 Local Delivery Support
- 👤 Intuitive and minimal user interface
- 📱 Optimized for mobile usability

## 🎨 UI/UX Design

The interface was designed in Figma to ensure:

- Smooth navigation flow
- Simple, user-centric layout
- Visually consistent components
